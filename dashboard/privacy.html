Privacy Policy

Job Pipeline Drive Uploader · Last updated November 23, 2026

What this app is

Job Pipeline Drive Uploader is a personal, non-commercial tool that is part of the job-pipeline research project. Its only function is to let the project's weekly GitHub Actions workflow upload the pipeline's own output files (aggregated, publicly available job-posting data) to a Google Drive folder owned by the project maintainer. It is not offered to the public, and it is used only by the maintainer's own Google account.

Google user data accessed

The app requests the Google Drive scope (https://www.googleapis.com/auth/drive) so it can create and update files in the maintainer's designated Drive folder. It does not read, collect, analyze, or store the contents of any other files in Google Drive, and it does not access Gmail, contacts, calendar, or any other Google service.

How data is used and stored

  • The OAuth refresh token is stored only as an encrypted GitHub Actions repository secret and is used only to authorize uploads to the maintainer's own Drive folder.
  • No Google user data is sold, shared with third parties, used for advertising, or used to train AI or machine-learning models.
  • No analytics, cookies, or tracking are used by this app.

Revoking access

Access can be revoked at any time from your Google Account's Third-party apps & services page. Revoking access stops all uploads immediately.
